# Design & Poster References

Folder ini untuk menampung gambar/file referensi desain visual dan poster marketing dari tim untuk MARKEN AI Studio.

## Cara Menambahkan Referensi:
1. Masukkan file gambar (`.png`, `.jpg`, `.webp`) ke dalam folder ini atau subfolder:
   - `docs/references/bold-pop/` (gaya vibran, poster suplemen/streetwear/energetik)
   - `docs/references/minimal-luxury/` (gaya elegan, skincare, parfum, estetika tenang)
   - `docs/references/warm-artisan/` (gaya hangat/kriya, kopi, makanan, kerajinan tangan)
   - `docs/references/clean-tech/` (gaya modern/gadget/fungsional)
2. AI Engine di `src/lib/studio/templates.ts` akan membaca prinsip visual dan mengkodifikasikannya ke dalam generator template MARKEN.
